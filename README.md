# Telegram Бот для обработки логов

Это приложение на Spring Boot, реализующее Telegram бота. Проект демонстрирует интеграцию Spring Boot с Telegram Bot API.

## Функциональность

Бот выполняет следующие функции:
- Мониторинг лог-файлов в реальном времени
- Автоматическое обнаружение ошибок в логах и отсчет об это

## Технологический стек

- Java 17
- Spring Boot 3.5.0
- Spring Boot DevTools
- Lombok
- Telegram Bot API (java-telegram-bot-api 5.7.0)
- Maven

## Требования

- Java 17 или выше
- Maven
- Telegram Bot Token (получить у @BotFather)

## Начало работы

### Локальная разработка

1. Клонируйте репозиторий:
```bash
git clone <url-репозитория>
cd demo
```

2. Соберите проект:
```bash
./mvnw clean install
```

3. Запустите приложение:
```bash
./mvnw spring-boot:run
```

## Структура проекта

- `src/main/java` - Содержит основной код приложения
  - `model` - Классы для обработки логов
- `src/main/resources` - Содержит конфигурационные файлы и ресурсы
- `pom.xml` - Конфигурация Maven проекта

## Конфигурация

Приложение требует настройки следующих параметров в файлах `application.properties` или `application.yml`:

```properties
# Токен вашего Telegram бота
telegram.bot.token=your_bot_token_here

# Путь к файлу логов
logging.file.path=path/to/your/logs.log

# Настройки мониторинга
monitoring.interval=2000
```

## Разработка

Проект использует Spring Boot DevTools для улучшения процесса разработки, предоставляя следующие возможности:
- Автоматический перезапуск приложения при изменении файлов
- Автоматическая перезагрузка статических ресурсов
- Улучшенная обработка ошибок

## Расширение функциональности

Бот может быть расширен следующими способами:
1. Добавление новых типов отслеживаемых событий
2. Реализация отправки уведомлений в Telegram
3. Добавление фильтрации логов по уровням (ERROR, WARN, INFO)
4. Интеграция с системами мониторинга
5. Добавление статистики и аналитики

## Устранение неполадок

### Частые проблемы

1. Бот не запускается
   - Проверьте наличие токена в конфигурации
   - Убедитесь, что путь к лог-файлу корректный

2. Логи не обрабатываются
   - Проверьте права доступа к файлу логов
   - Убедитесь, что формат логов соответствует ожидаемому

## Безопасность

- Храните токен бота в защищенном месте
- Не включайте конфиденциальные данные в логи
- Используйте переменные окружения для хранения чувствительных данных
